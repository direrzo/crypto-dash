# 🚀 CRYPTO DASH

A simple cryptocurrency dashboard built with **React** that fetches live data from the CoinGecko API and displays it in a clean, responsive interface.

## ✨ Features

- Displays a list of cryptocurrencies with:
  - Rank
  - Name & Symbol
  - Current Price (USD)
  - 24h Price Change (green/red indicators)
  - Market Cap
  - Total Volume
- Search functionality to filter coins by name or symbol
- Responsive design for mobile and desktop
- Loading states and error handling

## 🛠️ Technologies Used

- **React 18** (with Hooks: useState, useEffect)
- **React Router DOM** (for navigation)
- **Vite** (as build tool)
- **CoinGecko API** (free, no API key required)
- **Vanilla CSS** (custom styling, no frameworks)
